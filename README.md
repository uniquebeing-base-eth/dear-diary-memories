# Dear Diary Memories

Build the first polished visual prototype of a Farcaster Mini App called Dear Diary. This is NOT the final blockchain/backend implementation yet; focus on the mobile-first product UI and interaction prototype, while preserving an architecture that can later be fully decentralized with no custom backend. The product concept: users write a meaningful memory, Dear Diary routes generation behind the scenes to compatible AI image agents, with x402 payment and a 10% Dear Diary fee, then the generated artwork becomes a memory that can be saved, published, gifted, minted, or sold. Users should NOT see a list of agents unless necessary; agent selection is infrastructure behind the scenes. The visual direction MUST be inspired by the reference screenshots previously shared in this conversation: bold playful editorial mobile UI, oversized expressive typography, rounded cards, bright tasteful color blocks, soft gradients, illustrated/3D decorative elements, cute mascots, generous whitespace, polished animations, and a premium-but-fun social memory album feel. Do not make it look like a generic NFT/Web3 dashboard. Artwork is always the visual focus. Create a strong Home screen, Create Memory screen, generation/loading state, generated Memory detail/card, Gift flow, Mint Memory collectible presentation inspired by the latest reference, and My Diary screen with bottom navigation Home / Create / My Diary / Profile. Use placeholder/generated visual artwork and mascot/decorative elements as needed. Make the experience feel cohesive and production-quality, not a wireframe. Use simple language: Create a Memory, Gift a Memory, Mint Memory, Sell Memory. Include realistic mock data so the preview feels alive. Do not provision or use a database. Do not implement a centralized backend. Keep blockchain/AI integrations abstracted behind interfaces/placeholders for later decentralized implementation. Create an original Dear Diary visual identity rather than copying the references.
